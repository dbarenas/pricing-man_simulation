# Ferry Seat Occupancy Multi-Agent System

This repository contains the starter code for a proactive, asynchronous multi-agent system for maximizing ferry seat occupancy.

## Project Structure

- `src/`: Source code
  - `agents/`: Contains the different intelligent agents (e.g., `PricingAgent`).
  - `sdk/`: The Agent SDK for building new agents.
  - `event_bus/`: The event bus implementation (e.g., in-memory, Kafka).
  - `models/`: Data models and event schemas.
- `tests/`: Unit and integration tests.
- `main.py`: A script to run a simulation.
- `requirements.txt`: Python dependencies.
